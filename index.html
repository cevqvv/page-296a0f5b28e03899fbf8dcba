品牌简介

二次元是以订阅制机场为核心的网络加速平台，强调线路稳定、节点可切换，以及与主流代理客户端的兼容。与单一出口的传统 VPN 不同，二次元将流量套餐、节点池和客户端配置拆开：用户按月或按年获取订阅链接，再在本机客户端中导入，即可按场景选择普通线路、流媒体线路或游戏优化线路。

服务定位覆盖个人追番、多设备家庭与小型团队协作。节点侧提供常规中转与部分 IPLC 专线能力（视套餐而定），并针对常见海外流媒体做连通性优化。二次元官方网站是获取套餐说明、客户端选择指引与下载说明的唯一入口，请勿通过来路不明的安装包导入订阅。

品牌名称「二次元」保留其原有文化指向：面向动画、漫画、游戏与同人创作人群的跨境访问需求，同时保持通用加速能力，不把产品绑定单一内容站。

使用场景

海外追番与流媒体

在版权分区导致无法播放时，通过旗舰版或团队版的原生解锁节点访问常见视频平台。基础版提供基础解锁，适合对片源要求不极端的日常观看。

游戏与实时对战

旗舰版含 IPLC 专线游戏加速优化，用于降低跨区匹配的抖动。仍建议在客户端中单独选择游戏策略组，避免把大流量下载走专线。

资料检索与社交

学术页面、开源仓库、国际社交与创作社区访问，可使用普通线路节点池，把专线留给延迟敏感应用。

多设备与小型团队

同一订阅在手机、电脑与路由之间分配。团队版提高并发与带宽预留，并支持按业务拆分路由，减少互相抢占。

客户端选择

二次元不绑定单一闭源客户端。订阅为通用链接，导入主流开源或官方商店客户端即可。选择原则：系统官方商店优先、内核可更新、能分流规则。以下按平台给出二次元官网推荐组合，作为客户端选择的核心依据。

Windows

推荐 Clash Verge Rev 或 Clash Meta 图形客户端，便于订阅更新、规则分流与系统代理。也可使用 v2rayN 作为备选。安装后仅导入二次元订阅，不要叠加来源不明的配置包。

macOS

轻量需求可用 Clash 系客户端；需要策略组与网界面板时使用 Surge。Mac 请从开发者站点或二次元官网下载说明中的渠道获取，避免修改过的 dmg。

Android

推荐 Clash Meta for Android。开启分应用代理，可让番剧应用走解锁节点、游戏走低延迟节点、国内应用直连，节省套餐流量。

iOS 与 iPadOS

常用 Shadowrocket 或 Quantumult X。从官方商店购买正版后，用「订阅」功能粘贴二次元链接并开启定期更新。不要使用描述文件乱发的企业签。

路由器与电视盒

OpenWrt 等可刷机环境使用 Clash / Mihomo 内核。客厅设备建议单独策略，避免 4K 缓冲占满个人套餐额度；多成员共用请直接考虑团队版。

同一账号请控制在套餐允许的同时在线数内。客户端本身通常免费，付费发生在二次元机场订阅，而不是二次元客户端授权。

    先用延迟测试筛选节点，再开启系统代理或 TUN。无法播放时切换「流媒体」策略组，而不是反复开关整条 VPN。

常见问题

二次元是 VPN 还是机场？和普通梯子有何不同？

二次元以机场订阅方式提供多节点加速，用户在本地客户端中切换线路。相比单一 VPN 客户端内置的固定出口，机场更适合按追番、游戏、检索等场景分流，也便于更换节点而不重装软件。

如何从二次元官网完成客户端下载？

按本页客户端选择匹配系统：Windows 用 Clash 系，Android 用 Clash Meta，iOS 用商店内 Shadowrocket 等。安装后导入二次元订阅即可。客户端多为免费软件，费用对应的是节点与流量套餐。

三个套餐应该怎么选？年付是否更合适？

个人轻度与三设备以内选基础版；需要全节点流媒体与游戏专线选旗舰版；二十设备或需要定制路由选团队版。年付已分别标为 ¥150/年、¥350/年、¥850/年，长期使用成本更低。

能否解锁流媒体？基础版够不够用？

基础版提供基础流媒体解锁；旗舰版与团队版强调全节点原生解锁。若目标是稳定观看海外番剧与分区内容，优先旗舰版，并在客户端把对应 App 分到流媒体策略组。

同时在线设备超了会怎样？

基础版 3 台、旗舰版 5 台、团队版 20 台。超出后可能出现新设备无法连接或旧会话被挤下线。路由器科学上网也占用一个会话，请计入限额。

节点波动或无法连接时如何处理？

先更新订阅与规则，再换同区域其他节点。游戏请改走 IPLC 相关策略组。仍失败时通过工单反馈（旗舰版为优先支持）。不要频繁更换客户端重复导入同一链接。

订阅链接泄露是否能作废？

可以。在二次元用户中心重置订阅后，旧链接失效，再把新链接更新到各设备客户端。切勿把专属订阅发到论坛或网盘公开分享。
